# Printer sprite generation prompts

Built-in image generation was used on 2026-10-26. Each call used genuine transparency, its matching official model render as the hardware reference, followed by the repository's icon and hero as style references. The reference photos were not copied into the repository. Model-reference source links and asset usage are maintained in [branding](branding.md#printer-sprites).

## h2d

```text
Use case: stylized-concept.
Asset type: transparent pixel-art sprite for a read-only Bambu TUI printer dashboard.
Primary request: Create ONE new pixel-art depiction of the Bambu Lab H2D, using image 1 strictly as a hardware-shape reference. Images 2 and 3 are the project's existing pixel-art logo and hero: match THEIR chunky low-resolution pixel language, restrained palette, and flat pixel clusters. Do not reproduce a photograph.
Subject details: wide tall enclosed cabinet; two small inset dark displays at upper front left; large dark front glass door and tall dark side window; silver gray right body. Preserve the photo silhouette.
Composition: a single isolated printer, centered, entire machine visible, facing front and right side in the same three-quarter view as photo, with 12% clear transparent padding on every side. No AMS, spools, platform, room, people, UI, text, labels, logos or watermark. The printer is idle and the bed is empty; no print or motion marks.
Style: deliberate 64-to-96-pixel logical-grid artwork enlarged with nearest-neighbor to the output resolution. Every visible contour and interior detail made of crisp square pixel blocks; stair-step diagonals. Flat 2-to-3-tone panels, no smooth gradients, no photoreal shading, no soft edges, no anti-aliasing, no dithering. Use approximately 8 colors: deep charcoal #122226, dark teal #1B3537, muted teal #35565A, desaturated green #618B80, pale sage #90B49B, mint #A3E4BB, light bamboo #C5E6AD, pale cream #E4E9D8. Neutral silver panels should be represented with pale sage rather than true silver. Small mint display accents only. Read clearly at 112px tall on a dark dashboard. Genuine alpha transparency outside the object, no baked checkerboard. Hardware proportions and the distinguishing features above must be recognizable, but details should be simplified to the same visual family as the logo.
```
