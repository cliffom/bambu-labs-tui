One farm. A clearer view.

This dashboard shares the existing Bambu TUI monitoring session. It refreshes every three seconds while visible, and best-effort while hidden when browser notifications are enabled. Suspended or closed pages cannot deliver notifications. Stop the monitoring process to stop the server. In terminal mode, you can also disable Web Server in Config (,). Closing browser tabs leaves monitoring running.

The server listens only on 127.0.0.1 and has no authentication. Other programs and users on this computer can read display data and hide notices locally. Keep it local; remote access is not supported. For a terminal-free synthetic demo, run bambu-tui serve --demo; use bambu-tui serve for cloud-backed monitoring after saving a login.

Printer names, job names, and normalized telemetry appear here. Credentials, raw payloads, account information, and printer serial identifiers are excluded.

Inspecting a condition does not acknowledge, hide, snooze, or physically resolve it. Hide a notice locally here; terminal mode also offers acknowledgement, snooze, and restoration. Demo decisions are session-only. Use the printer or Bambu's applications for physical intervention.
